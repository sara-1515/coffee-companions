# ☕ Coffee Haven

A modern, responsive website showcasing Brewing Methods, Types, Fun Quiz, Origin and Coffee Pairing Guide


## 🚀 Features

- **Brewing Methods:** Learn various brewing techniques for different coffee styles
- **Types:** Learn about different types of coffees
- **Quiz:** Take a quiz to know your coffee better
- **Origin:** Read about the history of coffee and also some fun fact
- **Coffee Pairing Guide:** Some interesting guides based on your preferences

## 💻 Technologies Used

- HTML5, CSS3, JavaScript
- Responsive design with mobile-first approach
- Interactive maps for store locations
- Payment processing integration
- Contact form with validation

## 🛠️ Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/sara-1515/coffee-companions
   ```

2. Navigate to the project directory:
   ```bash
   cd coffee-companions
   ```

3. Open `index.html` in your browser or use a local development server.
